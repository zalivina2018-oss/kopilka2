# Копилка — Android 1.0

Локальное приложение для контроля личных финансов. Регистрация и подключение к банкам не требуются.

## Что уже реализовано

- доходы и расходы;
- несколько счетов с автоматическим пересчётом баланса;
- категории операций;
- главный показатель **«Можно потратить сегодня»**;
- месячный лимит расходов;
- цели накоплений и резервирование отложенной суммы;
- регулярные платежи, которые заранее уменьшают доступный дневной лимит;
- отчёт текущего месяца по доходам, расходам и категориям;
- динамика за последние 6 месяцев;
- экспорт всех операций в CSV;
- полная резервная копия в JSON;
- восстановление из JSON;
- локальная SQLite-база без внешнего сервера.

## Логика дневного лимита

1. Берётся текущий баланс всех счетов.
2. Вычитаются деньги, уже зарезервированные в целях накоплений.
3. Вычитаются регулярные платежи, которые ещё должны пройти в текущем месяце.
4. Если установлен месячный лимит, доступная сумма дополнительно ограничивается его остатком.
5. Получившаяся сумма делится на число оставшихся дней месяца, включая текущий день.

## Требования

- Android 8.0+ (minSdk 26)
- targetSdk 35
- Java 17
- Android Studio с Android SDK 35

## Сборка в Android Studio

Открой корневую папку проекта `fincontrol_android` в Android Studio. После синхронизации Gradle выбери **Build → Build APK(s)**.

## Автоматическая сборка через GitHub

В проект уже добавлен workflow `.github/workflows/build-apk.yml`. После загрузки проекта в GitHub открой **Actions → Build Android APK → Run workflow**. Готовый `app-debug.apk` появится в Artifacts как `FinControl-debug-apk`.

## Приватность

Версия 1.0 не содержит аналитики, рекламы, сетевых запросов или подключения к банковским аккаунтам. Финансовые записи находятся в локальной базе приложения. Для переноса данных используй резервную копию JSON.
